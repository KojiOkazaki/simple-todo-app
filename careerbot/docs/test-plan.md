# CareerBot テスト計画

## 1. バックエンド（自動・実装済み）

`cd backend && npm test`（`node --test`）。

| ファイル | 観点 |
|----------|------|
| `test/protocol.test.js` | メッセージ parse / build の正当性、不正入力の拒否 |
| `test/tools.test.js` | 模擬面接質問の巡回、回答添削ヒューリスティック、プロンプト生成、サマリ出力 |
| `test/e2e.test.js` | WebSocket で hello→auth_ok→audio_in→assistant_text→audio_out→idle の1ターン成立、モード切替、不正トークン拒否 |

現状: **13 tests / all pass**（mock プロバイダ、API キー不要）。

### 追加予定（Phase 2 以降）
- OpenAI Realtime アダプタの統合テスト（録画レスポンスでのモック化）
- 永続化（sqlite）の往復テスト
- セッションタイムアウト / 再接続
- 5往復以上の長い会話で履歴保持

## 2. ファームウェア（手動・実機）

| 観点 | 手順 |
|------|------|
| Wi‑Fi 接続 | 設定 → 接続成功 / 失敗時の再接続画面 |
| 音声キャプチャ | A ボタン押下中の MIC 入力 |
| 音声再生 | 受信 PCM のスピーカー再生 |
| ボタン入力 | A=会話, B=モード切替 |
| UI 状態遷移 | idle→listening→thinking→speaking→idle / error 表示 |
| 再接続 | サーバー切断からの自動復帰 |

## 3. E2E（実機 + サーバー）

| シナリオ | 期待 |
|----------|------|
| 起動 → 会話 → 応答再生 | ロゴ表示、A 押下で会話開始、音声応答が再生される |
| 面接モードで3ターン | 質問→回答→フィードバックが3回成立 |
| 長めの相談 | 5往復以上で履歴・文脈が保持される |
| ネットワーク瞬断 | 自動再接続し会話継続 |
